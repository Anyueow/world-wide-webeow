# Notion index

T-0.2 output. Every candidate source page for the site, with a read status.

**Why this file exists.** The first content pass claimed to have consolidated
"all seven pages named in the master spec". It had actually fetched four of
them and inferred the rest from search snippets. That is a large part of why
the content came out wrong. This index makes that failure mode impossible:
a page is either fetched in full and ticked, or it is not a source.

**Rule: do not cite a page you have not fetched.** Search highlights are not a
source. A page mentioned by another page is not a source until fetched.

Enumerated 2026-09-03 by SQL over the "Life in Pages" data source
(`collection://9326b3e0-a8af-44c4-9a95-5b7cd477f8b6`) rather than by semantic
search, because semantic search silently misses pages.

Legend: `[x]` fetched in full. `[ ]` not read. `[-]` deliberately out of scope.
